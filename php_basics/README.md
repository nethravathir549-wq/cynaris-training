# PHP Fundamentals - Week 3 Day 1

## Objective
Learn PHP fundamentals including variables, arrays, loops, conditionals, functions, form handling, validation, superglobals, and basic security.

## Files

- `basics.php` - Demonstrates variables, arrays, loops, conditionals, and functions.
- `form.html` - Student information form.
- `form_handler.php` - Handles form submission and performs server-side validation.
- `get_demo.php` - Demonstrates the `$_GET` superglobal.
- `session_demo.php` - Demonstrates the `$_SESSION` superglobal.

## Security

- Server-side input validation using PHP.
- Input sanitisation using `htmlspecialchars()`.
- Email validation using `filter_var()`.
- Basic protection against Cross-Site Scripting (XSS).
